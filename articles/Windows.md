# Windows

Article URL: https://support.optisigns.com/hc/en-us/articles/360034379293-Windows

### In this article, we'll install the OptiSigns player on a Windows PC and pair it with your OptiSigns account.

- [Install the OptiSigns Player](#InstallTheOptiSignsPlayer)
- [Use the Player Menu](#UseThePlayerMenu)
- [Pair the Player with Your Account](#PairThePlayerWithYourAccount)
- [Next Steps](#NextSteps)

The OptiSigns player turns any Windows PC into a digital signage player. It's also an easy way to try OptiSigns on your own laptop before you set up a dedicated screen.

The player runs on Windows 10 and Windows 11, 32\-bit and 64\-bit.

---

## Install the OptiSigns Player

[Download the OptiSigns installer for Windows](https://links.optisigns.com/win).

Open the downloaded file, **OptiSigns Digital Signage Setup**, to install the player.

![Downloaded OptiSigns Digital Signage Setup file in File Explorer with its right-click menu open](https://support.optisigns.com/hc/article_attachments/56920393411987)

When the installation finishes, the player opens full screen and shows a pairing code. Keep it on screen; you'll need it to pair.

![OptiSigns player on Windows showing a pairing code, with an arrow on the menu button at the top right](https://support.optisigns.com/hc/article_attachments/56920402466835)

---

## Use the Player Menu

Move the mouse to show three buttons at the top right of the player: **Exit Fullscreen**, **Menu** and **Close**. Select **Menu** to open the side menu.

![OptiSigns player side menu with Orientation, Restart, AutoStart and Fullscreen on Startup](https://support.optisigns.com/hc/article_attachments/56920393415955)

The side menu includes:

- **Orientation:** rotate the content to match how the screen is mounted.
- **Restart:** restart the player at a set time each day.
- **AutoStart:** open the player when Windows starts. On by default.
- **Fullscreen on Startup:** open the player full screen. On by default.
- **Advanced Options:** more settings for the player.

Because **AutoStart** is on by default, OptiSigns opens by itself the next time the PC starts.

## Pair the Player with Your Account

Go to [app.optisigns.com](https://app.optisigns.com/) and log in. If you don't have an account yet, select **Create Account**. You can also log in with Google, Microsoft or Facebook.

![OptiSigns portal log-in page with Google, Microsoft, Facebook and SSO options](https://support.optisigns.com/hc/article_attachments/56920393416595)

On the **Screens** page, select **Add Screen**.

![Screens page toolbar with an arrow on the Add Screen button](https://support.optisigns.com/hc/article_attachments/56920402469523)

Enter the pairing code shown on the player in **Pair code**, then select **Pair**.

![Add Screen dialog with a pair code entered and the Pair button highlighted](https://support.optisigns.com/hc/article_attachments/56920402470163)

| **NOTE** |
| --- |
| Codes are case\-sensitive, and the portal enters them in capitals. If the code on your player has lowercase letters, select **Use lowercase pairing code** and type it exactly as shown. If pairing fails with a case error, the portal switches this on for you, so check the code and select **Pair** again. |

The player changes to show that it's paired.

![OptiSigns player showing Paired](https://support.optisigns.com/hc/article_attachments/56920402471187)
