# MacOS

Article URL: https://support.optisigns.com/hc/en-us/articles/360041501494-MacOS

### In this article, we'll install the OptiSigns player on a Mac and pair it with your OptiSigns account.

- [Install the OptiSigns Player](#InstallTheOptiSignsPlayer)
- [Open the Player](#OpenThePlayer)
- [Use the Player Side Menu](#UseThePlayerMenu)
- [Pair the Player with Your Account](#PairThePlayerWithYourAccount)
- [Next Steps](#NextSteps)

The OptiSigns player turns any Mac into a digital signage player. It's also an easy way to try OptiSigns on your own laptop before you set up a dedicated screen.

The player runs on macOS 11 (Big Sur) and later, on both Apple silicon and Intel Macs.

---

## Install the OptiSigns Player

[Download the OptiSigns player for Mac](https://links.optisigns.com/mac).

In your **Downloads** folder, open the downloaded **OptiSigns Digital Signage** disk image (.dmg).

![Downloads folder in Finder with the OptiSigns Digital Signage disk image and Open selected](https://support.optisigns.com/hc/article_attachments/56921943460243)

Drag **OptiSigns Digital Signage** to the **Applications** folder.

![OptiSigns Digital Signage installer window with the app icon and the Applications folder](https://support.optisigns.com/hc/article_attachments/56921883956883)

---

## Open the Player

Open Spotlight and type **OptiSigns Digital Signage,** then select the app.

![Spotlight search with OptiSigns Digital Signage as the top hit](https://support.optisigns.com/hc/article_attachments/56921943464211)

The first time you open the player, macOS asks whether you're sure. Select **Open**.

![macOS prompt asking whether to open OptiSigns Digital Signage, with an arrow on Open](https://support.optisigns.com/hc/article_attachments/56921883958163)

| **NOTE** |
| --- |
| If macOS says it can't verify the app and won't open it, go to **System Settings** \> **Privacy \& Security**, scroll down, and select **Open Anyway** next to the message about OptiSigns Digital Signage. |

The player opens full screen and shows a pairing code. Keep it on screen; you'll need it to pair.

![OptiSigns player on a Mac showing a pairing code, with an arrow on the menu button at the top right](https://support.optisigns.com/hc/article_attachments/56921943466003)

## Use the Player Side Menu

Move the mouse to show three buttons at the top right of the player: **Exit Fullscreen**, **Menu** and **Close**. Select **Menu** to open the side menu.

![OptiSigns player side menu with Orientation, Restart, AutoStart and Fullscreen on Startup](https://support.optisigns.com/hc/article_attachments/56921883960211)

The side menu includes:

- **Orientation:** rotate the content to match how the screen is mounted.
- **Restart:** restart the player at a set time each day.
- **AutoStart:** open the player when the Mac starts. On by default.
- **Fullscreen on Startup:** open the player full screen. On by default.
- **Advanced Options:** more settings for the player.

Because **AutoStart** is on by default, OptiSigns opens by itself the next time the Mac starts.

## Pair the Player with Your Account

1. Go to [app.optisigns.com](https://app.optisigns.com/) and log in. If you don't have an account yet, select **Create Account**. You can also log in with Google, Microsoft or Facebook.

![OptiSigns portal log-in page with Google, Microsoft, Facebook and SSO options](https://support.optisigns.com/hc/article_attachments/56921883960851)

2. On the **Screens** page, select **Add Screen**.

![Screens page toolbar with an arrow on the Add Screen button](https://support.optisigns.com/hc/article_attachments/56921943470483)

3. Enter the pairing code shown on the player in **Pair code**, then select **Pair**.

![Add Screen dialog with a pair code entered and the Pair button highlighted](https://support.optisigns.com/hc/article_attachments/56921883962259)

**Note:** Codes are case\-sensitive, and the portal enters them in capitals. If the code on your player has lowercase letters, select **Use lowercase pairing code** and type it exactly as shown. If pairing fails with a case error, the portal switches this on for you, so check the code and select **Pair** again.

The player changes to show that it's paired.

![OptiSigns player showing Paired](https://support.optisigns.com/hc/article_attachments/56921943471891)
